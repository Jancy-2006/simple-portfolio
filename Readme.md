# Jancy – Personal Portfolio Website

## Description
This is a simple and responsive personal portfolio website created using only HTML and CSS as part of the Frontend Web Development Basics assessment.  
The website showcases my basic skills, projects, resume, and contact details.

## Author
Name: Jancy 
Course: Frontend Web Development Basics  
Project Type: Individual Assignment  

## Technologies Used
- HTML5
- CSS3

## Pages Included
1. Home Page – Introduction and navigation
2. About Me Page – Skills, hobbies, and basic information
3. Projects Page – List of sample projects
4. Resume Page – Education and skills
5. Contact Page – Contact form and details

## Key HTML Features
- Semantic HTML structure
- Navigation links between pages
- Ordered and unordered lists
- Contact form with required fields
- Proper headings and clean layout

## Key CSS Features
- Consistent color theme using CSS variables
- Box model (margin, padding, border)
- Hover effects and transitions
- Responsive design using media queries
- Form validation styling

## Responsive Design
The website is responsive and works on:
- Mobile devices (320px and above)
- Tablets (768px and above)
- Desktop screens (1024px and above)
